# GlowLab Protocol Tracker

A cute glowing-lab-creature-inspired website for organizing wet lab procedures.

## Features

- Home dashboard
- Editable protocol library
- Activity logs
- Statuses: Not started, In progress, Completed
- Individual step checkboxes and progress bars
- Editable titles, categories, dates, materials, procedures, and personal notes
- Search and status filters
- Automatic browser storage
- JSON export and import backups
- Mobile-friendly layout

## Important scientific note

The sample procedures are organized summaries based on the uploaded photographs. They are not substitutes for approved SOPs or current manufacturer instructions. Confirm all volumes, concentrations, temperatures, times, centrifugation settings, strains, safety requirements, and handwritten modifications before laboratory use.

## Privacy note

This version saves data in the current browser only. Do not enter participant identifiers, protected health information, passwords, confidential study data, or sensitive unpublished findings.

## Open in Visual Studio Code

1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Install the **Live Server** extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

## Publish with GitHub Pages

1. Create a GitHub repository, such as `glowlab-tracker`.
2. Open this folder in Visual Studio Code.
3. Initialize Source Control.
4. Stage and commit all files.
5. Publish or push to GitHub.
6. On GitHub, open **Settings → Pages**.
7. Choose **Deploy from a branch**.
8. Select `main` and `/ (root)`.
9. Save and wait for the public URL.
